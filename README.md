# WreckLab

## Overview
WreckLab is a self-hosted virtual IT training environment designed to simulate real-world IT Support and System Administration scenarios.

It is built using repurposed hardware and focuses on hands-on learning through system building, failure simulation, and troubleshooting.

---

## Purpose
The goal of WreckLab is to develop practical IT infrastructure and support skills, including:

- Windows Server and Active Directory administration
- DNS, DHCP, and Group Policy management
- Network configuration and troubleshooting
- User, group, and permission management
- System failure diagnosis and recovery

## Philosophy
> Build. Break. Fix. Understand.

WreckLab is designed to replicate real IT environments where systems are not clean or predictable, focusing on practical troubleshooting and root-cause understanding.
